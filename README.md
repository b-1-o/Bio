# Bio

> A gothic-inspired interactive bio / link-in-bio experience built with React, TypeScript, and motion.

Bio is a compact personal web experience focused on identity, links, visual atmosphere, embedded music, and polished motion.

## Highlights

- Gothic visual direction
- Responsive single-page experience
- Animated UI interactions
- Custom visual assets
- Embedded music section
- Motion-driven transitions

## Tech Stack

React 19 · TypeScript · Vite · Framer Motion · CSS

## Getting Started

```bash
npm install
npm run dev
npm run build
npm run preview
```
